# Contributing

This is a personal portfolio, but focused bug reports and accessibility, security, or performance improvements are welcome.

1. Use Bun 1.3.13 or a compatible newer patch release.
2. Run `bun install --frozen-lockfile`.
3. Keep changes small and avoid adding client-side weight without a measured benefit.
4. Run `bun run check` and `bun run test:e2e` before submitting a change.
5. Explain the user-facing outcome and include screenshots for visual changes.

Never commit credentials, contact-form submissions, generated reports, or local environment files.
